# MyBlog - Blog Application

## About the Project
MyBlog is a beginner-friendly, responsive Blog Application built using HTML, CSS, and JavaScript. Users can explore blog posts and try the blog creation interface.

## Features
- Home page with sample blog posts
- Login form with frontend validation
- Registration form with frontend validation
- Dashboard displaying saved blog posts
- Create and publish blog posts
- Browser local storage for saving posts
- Responsive design for mobile and desktop screens

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project Pages
1. Home
2. Login
3. Register
4. Dashboard
5. Create Blog

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Explore the application using the navigation links.

## Limitations
This is a frontend project. Login and registration do not use real authentication, and blog posts are saved in the current browser's local storage.
